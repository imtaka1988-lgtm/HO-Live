## 五、不建议随意改动的核心文件

| 文件 | 原因 |
|------|------|
| `assets/js/main.js` | 启动入口，改动会影响所有页面 |
| `assets/js/router.js` | 路由分发，render → #app 核心逻辑 |
| `assets/js/player.js` | HLS 播放器、多线路切换、streamUrl 兼容 |
| `assets/data/site-config.json` 的核心字段 | 品牌/直播间/赛程/广告的主数据结构 |
| `assets/vendor/hls.min.js` | 播放器依赖，543KB，不可删除 |
